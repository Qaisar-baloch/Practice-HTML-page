# Qaisar Khan – Personal Profile Website

A small multi-page personal website built with plain HTML (no CSS or JavaScript
frameworks), made as a first-semester web development lab assignment.

## Pages
| File | Content |
|------|---------|
| `index.html` | Home page with photo, intro and navigation buttons |
| `about.html` | About me, study topics, interests and goals |
| `projects.html` | Projects, plans and useful links |
| `contact.html` | Contact details and a message form |

## HTML elements used
- Headings and paragraphs (`h1`–`h3`, `p`)
- Buttons (`button`, including form submit/reset)
- Lists (`ul`, `ol`, `dl`, nested lists)
- Images (`img` with `alt` text)
- Hyperlinks (internal page links, external links, `mailto`)
- Semantic layout (`header`, `nav`, `main`)
- Form (`form`, `label`, `input`, `textarea`)
